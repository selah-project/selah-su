# Ngiring kana rendering Sunda Selah

Hatur nuhun parantos ngabantosan ngajantenkeun ieu rendering
langkung akurat, langkung écés, sareng langkung deukeut kana basa
Sunda. Teu kedah jadi sarjana: caritakeun naon nu katempo ku
anjeun, pasihkeun bukti nu aya, sarta bédakeun nu pasti tina nu
kira-kira.

## Ngalaporkeun kasalahan atawa ngajukeun koréksi

- Upami perkarana peryogi dibahas, aya langkung ti hiji bacaan nu
  mungkin, atawa teu écés kumaha koréksina mangaruhan kasaluyuan
  token (alignment) — buka **Issue**.
- Upami kasalahanana ogé koréksina écés duanana — buka **Pull
  request**.
- Pikeun perkara program atawa kaamanan/akun/privasi —
  [Selah Support](https://selahproject.com/support).

## Naon nu saé diasupkeun

Kitab, bab, ayat, kecap Ibrani nu patali; téks ayeuna; téks nu
diajukeun; alesan robahna; sarta bukti tina kamus, tata basa,
kontéks, atawa sumber nu geus diterbitkeun. Sebutkeun ogé naha
basa Sunda téh basa indung anjeun sarta naha anjeun tiasa maca
Ibrani langsung.

## Aturan ngédit file

File-file wangunna `<book>/<chapter>/<verse>.json`.

- Upami robahna keur duanana — édit bagian `translation` jeung
  `gloss` nu patali sakaligus.
- `book`, `chapter`, `verse`, `ref`, nilai-nilai `surface`
  Ibrani, sarta runtuyan jeung jumlah token — **ulah pisan
  dirobah**. Kasaluyuan nu ruksak téh kasalahan nu pangmahalna.
- **Nurutkeun tabél Jenengan**: יהוה → **Yahwe**; אלהים →
  **Elohim**; אדני → **Adonay**; שדי → **Shadday**; שאול →
  **Sheol**; חסד → **xesed**. Dina tempat Jenengan, **Yehuwa**,
  **GUSTI**, **PANGERAN**, jeung **Allah** teu ditarima. (Gusti/
  Pangeran keur juragan manusa mah merenah; keur *elohim* biasa,
  putuskeun dina unggal token — ulah ditolak sakabéhna.)
- Jaga tanda **⟨את⟩** jeung panambah ⟨dina kurung⟩; ulah
  dileungitkeun bari jempé. Kecap panambah dina kurung kudu
  **basa Sunda**.
- Di luar kurung — ngan hurup Latin Sunda: tanpa selapan Inggris,
  tanpa Sirilik, tanpa CJK, tanpa aksara Arab, tanpa Déwanagari.

## Ukuran métodena

Ibrani — nu munggaran. Upami dua bacaan bisa nangtung duanana —
témbongkeun bédana; ulah masihkeun pilihan minangka kapastian.
Ulah nyalin tina tarjamahan modéren nu ditangtayungan hak cipta.

## Digawé bareng AI

Wakcakeun upami anjeun ngagunakeun modél basa badag atawa
tarjamahan mesin — dibarengan ku pamariksaan anjeun sorangan.
Ulah ngintunkeun tumpukan téks nu teu dipariksa. Unggal kecap nu
diajukeun jadi tanggung jawab nu ngajukeunana.

## Lisénsi, catetan, jeung penilaian

Ku ngiring, anjeun negeskeun yén anjeun boga hak pikeun éta,
sarta satuju yén sagala nu ditarima bakal diterbitkeun dina
[CC BY-SA 4.0](LICENSE.md). Sajarah Git nyimpen catetan jeung
bukti nu muka. Para panjaga mariksa usulan jeung Ibranina, jeung
aturanana, jeung sumberna, jeung kasaluyuanana — tiasa nampi,
ngasakan babarengan sareng anjeun, ngantosan bukti salajengna,
atawa nolak kalayan alesan. Nu dipeunteun téh kecapna — lain
jalmana.
